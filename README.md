# Selekta

Selekta is a desktop database client for Mac, Windows and Linux: PostgreSQL, MySQL and MariaDB, SQLite, SQL Server and Redis, with production labelled on every screen and every edit shown as SQL before it runs.

**Download:** [selekta.kreasimaju.id](https://selekta.kreasimaju.id) · **Docs:** [selekta.kreasimaju.id/docs](https://selekta.kreasimaju.id/docs/)

This repository is for **bug reports and feature requests**. The source code is not published here.

## Report a bug

[Open a bug report](https://github.com/KreasiMaju/selekta/issues/new?template=bug.yml). Please include the Selekta version (Settings › About), your operating system and the database engine, and the steps that lead to the problem.

Never paste passwords, connection strings with passwords, or production data into an issue: issues here are public.

## Suggest a feature

[Open a feature request](https://github.com/KreasiMaju/selekta/issues/new?template=feature.yml). Say what you are trying to do; that helps more than a finished design.

## Security

Found a security problem? Do not open a public issue. Email [security@kreasimaju.id](mailto:security@kreasimaju.id) instead.
